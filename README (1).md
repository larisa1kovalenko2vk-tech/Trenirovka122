# Календарь: вода и тренировки

Годовой календарь-трекер: кликните на день, чтобы отметить выпитую воду (в литрах)
и тренировки (гантели, йога, танцы или свой вид — в часах). Дни автоматически
закрашиваются:

- 🟢 зелёный — выполнено всё (вода ≥ 0.5 л и все три вида тренировок)
- 🌸 розовый — выполнено частично
- 🔴 красный — ничего не отмечено

Один-единственный файл `index.html`, без сборки и без сервера — открывается
прямо в браузере.

## Как разместить на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `water-fitness-calendar`).
2. Загрузите в него файл `index.html` из этого набора (через "Add file" →
   "Upload files" на странице репозитория, либо через git — см. ниже).
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main** (или **master**), папка **/ (root)**
5. Нажмите **Save**. Через 1–2 минуты GitHub покажет ссылку вида
   `https://<ваш-логин>.github.io/<название-репозитория>/` — это и есть
   рабочий адрес вашего календаря.

### Через git (из терминала)

```bash
git init
git add index.html
git commit -m "Календарь: вода и тренировки"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/<название-репозитория>.git
git push -u origin main
```

Затем включите Pages, как описано в шагах 3–5 выше.

## Важно про хранение данных

Приложение сохраняет все ваши отметки в `localStorage` **того браузера**, в
котором вы его открываете — постоянно, без базы данных и сервера. Это значит:

- Данные не пропадут при обновлении страницы или перезапуске компьютера.
- Но они **привязаны к конкретному браузеру на конкретном устройстве**. Если
  откроете сайт на телефоне или в другом браузере — там будет пустой календарь.
- Очистка данных браузера ("очистить историю и файлы cookie") сотрёт и записи
  календаря.

Если нужно, чтобы данные были одинаковыми на всех ваших устройствах, это уже
потребует настоящей базы данных (например, Firebase) — могу сделать такой
вариант отдельно, если пригодится.
